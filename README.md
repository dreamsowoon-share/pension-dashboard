# 연금 대시보드 (공유용)

퇴직 후 연금을 **얼마씩 · 언제부터 · 어떤 순서로** 꺼낼지 계산해 보는 화면입니다.

## 쓰는 법

주소를 열고 **1-1 내 정보 입력**부터 채우시면 나머지가 자동으로 계산됩니다.

## 넣은 값은 어디에 저장되나

**여러분의 브라우저에만 저장됩니다.** 서버로 보내지 않고, 이 저장소에도 들어가지 않습니다.
- 다른 기기에서 열면 값이 비어 있습니다 (기기마다 따로 저장됩니다)
- 비공개 브라우징에서는 저장이 안 됩니다 — 화면 맨 위에 알려 드립니다
- 브라우저 기록을 지우면 값도 지워집니다

## 무엇이 들어 있나

| | |
|---|---|
| 1부 | 현재 상황 파악하기 — 내 정보 입력 |
| 2부 | 모으기와 불리기 — 적립 계획 · ETF 고르기 · 포트폴리오 & 실전 매매 · 모으면 얼마가 되나 |
| 3부 | 연금 찾기 — 개시 나이 · 퇴직소득세 · 건보료 · 현금흐름 · 세금 · 잔액 |

**ETF 찾기(국내 1,168종목 · 245그룹 비교)가 화면 안에 들어 있습니다.**
2-2 에서 종목을 고르고 「담기」를 체크하면 2-3 포트폴리오로 넘어옵니다.

## 만든 것

- 외부 스크립트를 **하나도 쓰지 않습니다** — 파일 하나로 다 돕니다
- 계산은 국민연금·연금소득세·건강보험료 규칙(2026년 기준)을 따릅니다
- 검증이 필요한 값은 **부록 A** 에 따로 모아 두었습니다
